> 命名勘误：网传中文名"乐伟"无任何来源支持。可确认的实名是英文 **Le Liu**（GitHub 显示名 + macOS 版应用签名均为 "Le Liu"，见[GitHub 主页](https://github.com/liulex)、[feedback issue #2366](https://github.com/Snipaste/feedback/issues/2366)——macOS 13 登录项里显示的开发者名就是 Le Liu）。按拼音回推中文名很可能是"刘乐"，但无直接来源，本文一律用他的网名 **levie**。
>
> 职业背景勘误：GitHub 上他属于 NVIDIAGameWorks 组织，但**这不能证明他在 NVIDIA 工作过**。该组织是 NVIDIA 给申请 GameWorks 源码访问权的注册开发者开的（申请流程见 [NVIDIA 官方页](https://developer.nvidia.com/gameworks-source-github)），公开成员数以千计、全是随机开发者（[成员列表](https://github.com/orgs/NVIDIAGameWorks/people)）；GitHub 检索他在该组织的 commit / issue / PR 均为 0。他的可证背景只有一条线：2016 年发布 Snipaste 时是博士研究生，当年秋天在参加校招、次年（2017）毕业（[V2EX 发布帖及其回复](https://www.v2ex.com/t/295433)）。

## 访谈清单

公开可查的正式访谈只有一篇：

1. **2016-08 · 少数派**《幕后丨他做了最强免费「截图」工具 Snipaste 后，还有上万字的话想说》 — https://sspai.com/post/35097
   - 产品本体是贴图不是截图："Snipaste 的本体是贴图"，截图只是"为了让贴图功能更好用而增加的一个辅助"。
   - 贴图点子来自姐姐："一个场景就是贴图功能，主要是我姐的需求，我觉得很不错，就开始开发了。"
   - 免费是推广策略 + 责任边界：希望更多人体验贴图提升效率；同时"目前无法给大家提供稳定的售后服务，没办法对付费用户负责"。
   - 功能观："并不是我特意想把 Snipaste 做得功能特别多，而是如果要用贴图的方式来提高工作效率，它就需要有这些功能。"
   - 给独立开发者四点建议：产品必须自己有需求、有竞品不必打退堂鼓、试试做桌面产品、"从 0 到 0.1 很难，所以不要犹豫太多，想做就去做"。
   - 自我定位清醒："说到专业的截图，比 Snipaste 优秀的软件并不少。"

此外无第二篇。小众软件 2016 年的报道（ https://www.appinn.com/snipaste/ ）是评测非访谈；检索"利器 / 播客 / 独立开发者访谈 + levie"均无结果（Spotify 上的"Snipaste 截图术"播客是第三方教程，非本人）。

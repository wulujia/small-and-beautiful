# 沉浸式翻译

> 在"整页替换式翻译"和"硬啃原文"之间做双语对照阅读 ｜ immersivetranslate.com ｜ Owen Young（@OwenYoungZh）｜ 2022 年上线 ｜ 团队规模未公开（2023.5 起为推文科技旗下独立子公司）｜ 浏览器扩展 / AI 翻译 / 出海 ｜ 营收未公开（免费 + Pro 订阅，Pro 约 $8/月）

## 缝隙切入点

传统网页翻译是"整页替换"：译文盖掉原文，想学语言、想核对原意的人两头不讨好。Owen 的灵感来自读萧伯纳剧本《巴巴拉少校》的双语版——"一段原文 + 一段译文"的排版让他决定把这种阅读体验搬进浏览器 [2]。他先 fork 了开源翻译插件 TWP，花很短时间实现了双语对照效果（2022-11-05 基于 TWP 开发，11-29 决定从零重写，2023-01-18 重写版上架 Chrome 商店）[4]。产品核心是智能识别网页主内容区，以"原文 + 译文"段落对照展示、保留原布局，比同类插件对原网页的"侵入性"更低 [1][2]。

## 时机

- 争议梳理档案记为 2022 年 10 月上线，Owen 自述 11 月初基于 TWP 开发，两者相差数周 [2][4]。
- 上线三个月后赶上 ChatGPT/OpenAI API 爆发（2023 年 3 月），沉浸式翻译把 OpenAI、DeepL 等 10 余种（后扩至 20+）翻译引擎聚合成可自选后端，成了普通人体验"AI 翻译质量跃升"的最短路径 [1][8][10]。
- 2023-05-25 公告被收购时，官方口径是"过去 5 个月积累了 40 万用户"——正好踩在 AI 工具需求爆发的窗口上 [1][3]。

## 差异化

- 双语对照而非替换，服务"既要读懂、又要看原文"的人群 [2][8]。
- 翻译引擎可自选、可自带 API key：DeepL、OpenAI、Google、Bing 等 [1][8]。
- 场景纵深扩张：网页 → PDF → 双语 EPUB 电子书 → YouTube/Netflix 双语字幕 → 漫画/图片翻译，全平台（Chrome/Edge/Firefox/Safari/iOS/Android）[8][9][10]。
- 阮一峰的用法佐证了场景纵深："对我最有用的功能是制作双语 EPUB 电子书"，并在周刊 266 期专文实测 [8][9]。

## 第一批用户/冷启动

- Owen 是多年独立开发者，此前做过 Buzzing.cc（英文社区信息聚合），在开发者圈已有关注度；早期靠开发者和技术爱好者社群口碑传播 [2][5]。
- 打法是 Build in Public：Twitter、Telegram 群、GitHub 公开仓库收集反馈，硬地骇客 EP56 专门讨论了"早期用户群的获取与口碑建设"和"社交媒体在产品增长中的作用" [5]。
- 关键放大器：阮一峰《科技爱好者周刊》第 254 期（2023-05）刊出"作者自荐"，随后 266 期（2023-08）阮一峰亲自实测推荐 [8][9]。
- 结果：5 个月 40 万用户（截至 2023-05）[1][3]。

## 收入与定价

- 2023 年 8 月推出 Pro 会员，上线价 69 元/月，包含 OpenAI/DeepL 官方额度；V2EX 上被吐槽"价格劝退"，但也有人认为"这是很健康的商业模式" [7]。
- 免费策略激进：不买 Pro 也能用几乎全部功能，自带第三方 API key 即可零成本使用——免费版本身就是获客产品 [7]。
- 现行 Pro 约 $8/月（年付折算），2025 年 618 促销年费约 405.72 元；Pro 含每月 2000 万 token 高级翻译额度、1000 页 PDF Pro 解析等 [11][12]。
- 订阅收入、转化率均未公开；收购金额也未披露 [1][3]。

## 内容与增长

用户量增长线（各时间点均有出处）：
- 2023-05：40 万（收购公告）[1][3]
- 2024-04：超 150 万安装（硬地骇客 EP56 时期）[5]
- 2024 年底：超 500 万 [2]
- 2025 年：突破 1000 万 [2]
- 2026 年官网宣称：全平台超 2000 万用户；Chrome 商店单端超 200 万、评分 4.4，并被 Google 评为 Chrome 2024 年度精选扩展 [10][13]。

增长基本不靠投放：KOL 与内容口碑（阮一峰两次推荐、少数派专文、即刻年度产品盘点）+ 双语字幕/双语电子书等自带传播的使用场景 [8][9][13]。

## 社区

- Telegram 用户群 + GitHub 公开仓库当反馈平台是社区主阵地 [4][2]。
- 副作用：用 GitHub 公开仓库做官网和反馈入口，让部分用户误以为它是开源项目。2023 年 10 月"假开源"争议爆发后，Owen 发长文逐条反省整改（移除误导性文件、明确标注"并非开源软件"），承认"源代码可用不等于开源" [4]。

## 转型

三次身份转变，节点都很清晰：
1. **个人项目 → 公司**：2023-05-25 宣布被推文科技（funstory.ai，AI 网文出海公司，2017 年成立，曾获连尚网络、喜马拉雅、联想之星等投资）收购，金额未披露，双方成立独立子公司（沉浸式翻译（深圳）有限责任公司）专门运营，Owen 继续负责产品和技术 [1][3][14][15]。
2. **程序员 → 产研负责人**：Owen 在 2024 年 8 月播客里自述从写代码转向带产研，并谈"做穷人也能用的产品" [6]。
3. **信任危机（2025-08）**：网页快照分享功能致用户敏感内容（合同、保单等）被搜索引擎收录，官方回应"用户主动分享导致"并紧急下架该功能 [16][2]；8 月 9 日公告拟限制第三方 API，引发强烈批评，当晚删除公告并道歉，承诺"永远不会限制用户使用任何第三方翻译服务" [17][2]；另有竞品"流畅阅读"作者单方面陈述称创始人在 Telegram 群曝光其住址、数分钟后撤回 [2][18]。此外许可证从 MPL → AGPL → EULA、2023 年 11 月起彻底闭源，也是社区长期不满的来源 [2]。

## 如何保持小

- Owen 的个人哲学是"注意力自由"高于财务自由：裸辞大厂（腾讯）后独立开发三年，定居深圳大亚湾，月租约 1500 元，用低成本生活换取做产品的自由度 [5][6]。
- 产品哲学同源："做穷人也能用的产品"——免费版始终保持完整可用，自带 API key 就能白嫖全功能 [6][7]。
- 卖给推文科技但保留独立子公司结构、自己只管产品和技术，是他"要产品不要管公司"的取舍 [1][3]。

## 开放问题（值得当面问创始人的）

1. 2023 年 5 月，产品上线才 7 个月、40 万用户正在爆发期，为什么决定在那个节点卖给推文科技？条款里最看重什么？三年后回头看，卖对了吗？
2. 免费版慷慨到"自带 key 全功能免费"，Pro 的实际转化率是多少？模型 token 成本靠什么撑住？
3. 2025 年 8 月那 12 个小时——限制第三方 API 的公告是怎么被拍板、又是怎么被推翻的？那次危机改变了团队的什么？
4. 从 MPL 到 AGPL 到 EULA、从公开仓库到闭源，哪一步是你最不情愿但认为必须做的？
5. "注意力自由"和管一个千万级用户产品的产研，这两件事今天还兼容吗？如果重来，还会把它从个人项目变成公司吗？

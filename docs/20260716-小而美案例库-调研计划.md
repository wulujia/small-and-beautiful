# 小而美公司/产品案例库 —— 广度调研计划（Batch 1 → 200 家 + 精选深挖）

## Context（为什么做这件事）

Luca 的第一本书《夹缝生长——小而美的产品创业》已完稿交出版社，是一套"方法论骨架"（8 部分 40+ 章，每章回答一个问题：缝隙/时机/PMF/第一批用户/收入/留存/转型/如何保持小…）。

这个新项目是它的**延伸**：建一个**可搜索的"小而美公司/产品"结构化案例库**——近期做成公开网站，长期沉淀为第二本书的素材与读者池。检索模型是**按问题查**（用户搜"冷启动"，库返回一整列在该维度有强故事的公司对照），所以数据是一张 **公司 × 书的章节维度** 的稀疏矩阵。

**当前唯一目标：先用数量把底座建起来。** 沿"公司 + 产品"两个维度探索出 **100 → 200 家**，在其中标出 **20–30 家创始人可触达的**，为后续一手深访铺路。本计划只做"广度调研 + 精选标记 + 约访草稿"，**不涉及网站开发，也不实际发送任何约访**（对外动作由 Luca 拍板）。

## Schema

**广度层（`companies.md` 每行一家，极薄）字段：**
`名称 | 一句话缝隙 | 对标巨头 | 品类 | 国家 | 创始人 | 成立年 | 团队规模 | 类型tag | 营收(若知) | 状态 | 触达度(高/中/低) | 最佳渠道 | 来源链接`

- `品类` 用 10 类分类法：开发者工具 / 隐私·分析 / 生产力·笔记 / newsletter·内容工具 / 独立 Mac·iOS 应用 / 垂直 SaaS / 电商·插件生态 / 信息付费·社区 / 独立游戏 / 本地优先·开源 infra
- `对标巨头` = 它切了谁的缝隙（Plausible→GA、Ghost→Substack、Basecamp→Asana）——按问题查之外最值钱的检索维度
- `触达度` 判定优先级：Indie Hackers 实名主页 / 播客嘉宾 / build-in-public 的 X / 官网公开个人邮箱 / 公开营收页（华人：即刻·X·知识星球·公众号）

**深度层（`deep/<slug>.md`）在广度字段上，沿书的章节维度补"有强故事就填"的稀疏笔记（每条附来源）：**
`缝隙切入点 · 时机 · 差异化 · 第一批用户/冷启动 · 收入&定价 · 内容&增长 · 社区 · 留存 · 转型 · 如何保持小`

## 研究流水线（可复用，由我用 fan-out 子代理跑）

一条 6 步流水线，每批都跑一遍：

1. **Harvest 采集** — 按信源分派多个 Explore 子代理，各抓一个"蓄水池"，产出原始候选行（名称+官网+一句话+来源）。
2. **Dedupe 去重归一** — 跨信源按名称合并成单一候选表。
3. **Grade & Tag 分级打标** — 套准入标准（小/独立/缝隙/真收入）过滤，剔除 VC-规模化假样本；补齐品类、类型tag、对标巨头、触达度+最佳渠道+来源。
4. **Store 存档** — 写进 `companies.md` 表。
5. **Select 选深挖对象** — 从已分级集里挑 20–30 家：`触达度高` × `缝隙故事强` × `跨品类/跨地域多样`。
6. **Deep + Outreach 深挖与约访草稿** — 对选中的：沿书维度补 `deep/<slug>.md`；写 `outreach/<slug>.md`（个性化约访话术，模板："在写一本中文《夹缝生长》案例书，想收录你的『缝隙故事』"——正中爱分享型创始人）。**只出草稿，不发送。**

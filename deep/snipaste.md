# Snipaste（Levie）

> 在"截图工具"红海里，把"贴图"（把任何图片/剪贴板内容钉在屏幕最上层当临时便签）做成产品本体，截图只是入口 ｜ snipaste.com ｜ Levie（GitHub 账号 liulex，发布时为博士研究生）｜ 2016 年公开发布（2014 年春节始于前身 PicNotes）｜ 1 人，至今 ｜ 桌面工具 / 免费+买断制 Pro / solo ｜ 营收未公开（仅知收费前 22 个月捐赠约 ¥19,000）

## 缝隙切入点

Snipaste 的前身叫 PicNotes，2014 年春节开写，初衷是"用图片来做笔记，临时的笔记，所以是贴在屏幕上而不是放在笔记本里"[2]。贴图这个点子甚至不是作者自己的："最开始贴图的功能应该是我姐的需求，我觉得很不错，就开始开发了"——之后他自己变成重度用户，师兄又贡献了旋转图片、撤销标注等需求 [2]。2015-12-04 改名 Snipaste（Snip + Paste，截图 + 贴图）[1][2]。

关键的产品判断：截图是红海，但截图只是获客入口。作者在发布帖里的原话："虽然截图很好用（……），但是这软件的本体真的是**贴图**"[1]。用户截下的图、复制的文字和颜色值，按 F3 就变成一张悬浮在所有窗口之上的"便签"，退出时自动备份、下次启动完美恢复 [1][2]。对照资料、抄参数、比稿、记临时信息——这类"需要把一块屏幕内容钉住"的高频小场景，当时没有任何主流工具认真做过。

## 时机

与"抢风口"相反，Snipaste 是典型的"熟了才发"：2016-07-28 在 V2EX 公开发布时，作者已经"自用了两年多，平时遇到的 bug 基本都修复了"，加上开发时间号称三年 [1]。发布即爆：这条帖子最终积累 751 条回复、23 万+ 浏览 [1]，小众软件、少数派等渠道随后跟进报道，少数派在一个月内做了万字采访 [2][19]。2016 年的 Windows 生态里，"不挂 QQ 就能用的高质量免费截图工具"本身就是稀缺品——七年后还有用户抱怨为了长截图"需要频繁启动 QQ"[11]。

## 差异化

- **贴图为本体**：剪贴板里的图片、文字、颜色都能一键钉屏，贴图可分组、缩放、旋转、调透明度，自动备份恢复 [1][2]。竞品出现前，这个功能在 Windows 上近乎独家。
- **免费且无限制**：发布时"Snipaste 完全免费，无任何功能限制"[1]，对照当时"截图要挂 QQ"的默认方案是降维打击。
- **克制的功能观**：面对"功能太多了"的说法，作者的回应是"并不是我特意想把 Snipaste 做得功能特别多，而是如果要用贴图的方式来提高工作效率，它就需要有这些功能"[2]。
- **宁缺毋滥的工程洁癖**：拒绝上"有瑕疵的长截图"。2016-12 他解释过：浏览器外"似乎没有接口可以提供某个窗口一次滚动是滚了多少像素"，只能靠图像拼接，而"拼接结果总会有瑕疵……所以不想使用拼接的方法。总之，不好实现"[8]。这个坚持后来成了最大的软肋（见"转型"节）。
- **快**：即使在 PixPin 崛起后，仍有用户因为 PixPin"反应迟缓""有点卡"而留在 Snipaste，认它的响应速度 [12]。

## 第一批用户/冷启动

- 公开发布前，用户只有身边"约十来个"人，靠两年多自用把 bug 磨掉 [1]。
- 冷启动就是一条 V2EX 帖子（2016-07-28）：751 回复、231,288 浏览，评论区甚至主动喊出"付费使用也不介意"[1]。
- 发布后头两个月高频迭代回应社区：v1.3（08-01）、v1.5（08-15）、v1.7（09-18），每个版本都发 V2EX 更新帖 [3][17][18]。
- 放大器是工具媒体：小众软件 2016 年专文《历时三年开发的「截图 + 贴图」工具》[19]，少数派 2016-08 万字采访《他做了最强免费「截图」工具 Snipaste 后，还有上万字的话想说》[2]。

## 收入与定价

**先免费两年，再收费**，且作者把逻辑说得很透：

- 为什么免费（2016）："我希望更多的人去尝试 Snipaste，去体验贴图功能如何可以提升你的工作效率，这是我最终选择将 Snipaste 免费的根本原因。另外，也是因为我目前无法给大家提供稳定的「售后服务」，没办法对付费用户负责，所以 Snipaste 现在不能是付费软件"[2]。他同时留了口子，预告要写"为什么明明可以收费，却要选择免费"[3]。
- 为什么后来收费（2018）："我希望推广贴图的概念……如果一开始就收费，大家只会觉得这是一个一上来就收费的**截图**软件，就不会有很多人愿意尝试"；"基础功能已经完善、稳定，推广目的也已达到，所以是时候向要求更高的用户提供收费功能了"[4]。
- **捐赠数据（作者主动公开）**：收费前 22 个月共收到捐赠约 ¥19,000、1,343 人次——支付宝 ¥10,249.92（690 人）、微信 ¥7,299.51（628 人）、PayPal $243.04（23 人）、比特币约 0.0059 BTC（2 人）[4]。这组数字是"用爱发电天花板"的罕见实证：23 万浏览的爆款 + 两年口碑，捐赠月均不到 ¥900。
- **2.0 专业版（2018-07）**：定价 99 元，首发八折 80 元，"大版本买断，不是订阅制"；免费版继续更新但以 bug 修复为主；专业版一次性加入 24 个新功能 [4][10]。
- **现行定价（2026）**：跨平台桌面版单设备 45 元 / 3 设备 99 元 / 微软商店版 10 设备 99 元（海外 $8.99 / $19.99 / $19.99），永久使用、子版本免费更新，未来升级 Snipaste 3 有折扣 [5][6][7]。
- **免费边界**：2.x 仅对个人用户免费，商用需购专业版；1.x 连商用都免费 [5][6]。

## 社区

- 反馈主阵地是 GitHub 仓库 Snipaste/feedback——只放 issue 和 wiki，不放源码（早年考虑过开源，被社区劝阻后搁置）[3][6][8]。更新通知走 Telegram 频道 [9]。
- 社区最著名的一根刺：滚动截屏 issue #19，2016-08-03 创建，作者次日回复"未来会加入该功能"，至今仍是 Open 状态、里程碑"next"[8]。十年间它成了催更圣地："从 2016 催到现在""要么直接说不加"，也有人明说"如果加了长截屏，我肯定立刻就入专业版"[8]。
- 2023 年后社区情绪明显转向：V2EX 出现《Snipaste 7 年了都没有长截图，有点难顶》（2023-11）[11]、《之前为何没人说 PixPin 这么好用》（2024-11，有人评价"Snipaste 现在不思进取"）[12]；小众软件论坛 2025-06 的长帖批评作者"许多傲气"，对明确的用户需求"坚持不开发"[13]。

## 留存

贴图工作流的粘性极强：抱怨最凶的用户也走不掉——《7 年了都没有长截图》的楼主自称用了 6-7 年专业版，喜欢它"小而美"，诉求只是"在保持精简的前提下加长截图和 OCR"，而不是换工具 [11]。PixPin 功能全面占优后，仍有用户因流畅度差异留在或退回 Snipaste [12]。作者 2016 年的判断（让用户体验到贴图对工作效率的提升，就会留下 [2]）在十年尺度上基本成立。

## 转型：不转型，守城

Snipaste 没有转型故事，只有一场被动的守城战：

- **2023-11-07**，PearOCR 作者 knightjun 在 V2EX 发布 PixPin：截图 + 贴图 + 离线 OCR + 长截图 + GIF 录制，全部免费——正是 Snipaste 用户催了七年的功能清单 [14]。评论区直接把它当"Snipaste 平替"，迁移潮开始 [14][12]。历史在重演：PixPin 用免费换传播，就是 levie 2016 年的打法。
- **作者的回应**（据小众软件论坛用户整理）：2023-12 承诺会做滚动截图和文字识别，"但要等到 Snipaste 3"[13]。
- **实际动作**：2023-12-28 推出 Linux 公测版（2.8.8 Beta）[10][15]；2024-09-10 发布 2.10 桌面正式版 [10]；**2025-12-08 的 2.11 才终于加入 OCR，且是专业版付费功能** [9][10]——竞品免费送的东西，Snipaste 拿来卖。滚动截屏至今没有，Snipaste 3 至今未发布（最新版 2.11.3，2026-01-18）[9][10]。
- 对手在变重：PixPin 3.0（2026-04）已有专业设计师参与，走"核心功能免费 + 会员"路线 [16]，付费永久版约 158 元 [13]。轻重之势逆转——现在 Snipaste 才是"更便宜、更克制"的那个。

## 如何保持小

- **一个人，近十年**：2014 年动手时是博士生，课余项目 [1][2]；2016 年发布、2018 年商业化、2019 年 Mac Beta（2.2）、2023 年底 Linux Beta、2025 年 OCR，全部一人完成 [2][4][10]。
- **节奏自己定**：2016 年发布季两个月连发多版 [3][17][18]；此后放缓为大约 1-3 个月一版，2025 Q4 到 2026 年初又有一波密集更新（2.10.8→2.11.3 共 6 版）[9][10]。慢，但从未断更——© 2016-2026 [5]。
- **用买断制匹配单人产能**：大版本买断 + 子版本免费更新，不背订阅制的持续交付承诺 [4][6]。
- **拒绝为竞争改变优先级**：长截图催了十年不做（技术方案不完美就不上）[8]，OCR 晚到两年且直接进付费版 [9][10]。代价是口碑损耗 [11][12][13]，换来的是单人可维护的边界。
- **不开源、不团队、不融资**，商业模式简单到只有一张价目表 [3][5][6]。

## 开放问题（值得当面问创始人的）

1. 收费前 22 个月捐赠只有 ¥1.9 万，这个数字当时对你的冲击有多大？它在多大程度上促成了 2.0 收费的决定？今天 Snipaste 的年收入够全职生活吗——它到底是你的主业还是副业？
2. PixPin 2023 年用"免费 + 你缺的所有功能"打过来，本质上是把你 2016 年的免费策略反过来用在你身上。那个冬天你有没有动摇过？OCR 最终做成专业版付费功能而不是免费跟进，是深思熟虑的定位（不打免费战），还是变现压力？
3. 长截图从 2016-08-04 的"未来会加入该功能"到今天整整十年：这是工程洁癖（拼接有瑕疵不如不做）、优先级问题，还是某种对用户投票的抗拒？Snipaste 3 还会来吗？
4. 一个人维护 Windows/macOS/Linux 三平台近十年，最接近放弃是哪一次？如果 2018 年拿捐赠和首发收入组一个 3 人小团队，今天的 Snipaste 会更强，还是已经死了？
5. 你 2016 年给独立开发者的建议是"从 0 到 0.1 很难，想做就去做"[2]。十年后，你会给"已经做到 0.8、被免费竞品围攻"的那个自己什么建议？

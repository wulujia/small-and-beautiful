# 陶新乐（Tolecen）— 白描

> L2 创始人资料库 · 聚焦本人公开表达。公司/产品故事见 `deep/baimiao.md`。

## 创业时间线

- **2012** 毕业于山东理工大学通信工程专业；此后 5 年在北京互联网行业：游艺星际（北京）iOS 工程师 → 中体彩科技发展有限公司 iOS 工程师 → 北京爱宠联盟科技联合创始人（宠物社区 App"宠物说"）。（猎云网 2017）
- **2015 前后** 注册北京优零科技有限公司（白描官网备案"京ICP备15039323号"），任 CEO。
- **2016-12** 业余做出诗词 App《西江月》（第一款个人作品序列产品）。（博客）
- **2017-06-06** 从公司辞职（"辞职的动力就是爱情"，结束异地恋），成为自由开发者，靠外包项目过渡。（博客《我的 2018》《白描的这半年》）
- **2017-06 中旬** 和女友聊天，"我给你做一个吧！"当晚交出粗糙版本；两天完成产品设计到上线推广。（博客/猎云网）
- **2017-06-19～23** 白描 iOS 版上架 App Store（本人不同文章记为 06-19/06-21/06-22，猎云网记 06-23；9 周年文以 2017-06-21 为准）。上线次日被少数派首页推荐。
- **2017-07-01** 免费转付费 3 元（平衡百度 OCR API 成本）。
- **2017-08-23** 1.6.0"重生版"，女友白灵筠操刀 UI/图标，团队开始扩员。
- **2017-10-04** 《西江月》获 App Store 首页推荐，带动白描下载。
- **2017-11-29** 安卓版上线，首发选酷安，2.5 天破 1 万用户。
- **2017 年底** 两端约 9～10 万用户，日活 6500；获少数派年度应用、最美应用年度榜前五。
- **2018** 新增文件扫描（05-01）；年底 115 万用户、日活 3 万；团队 3 人；获豌豆荚设计奖年度应用；收入超过上班时期。
- **2019** 上线微信小程序，凑齐三端；年底 270 万用户；同期产品线：犀译、两个西柚、白描取字、晓时。
- **2020** 网页版、Mac 版、离线 OCR、飞书版、身份证扫描；华为 HMS 大赛 TOP20 + 星光创意奖；年底 560 万用户。
- **2022** Windows 版发布（即刻帖，2022-09）；华为应用市场下载超 1700 万（中国日报，2022-02）；产品线扩展出白描证件照、方弗相机。
- **2023-12** 上少数派播客，称白描为"千万级独立 App"，团队已多人、全平台。
- **2026-06** 白描 9 周年：推出鸿蒙版与新产品"白描 PDF"（网页版 pdf.baimiaoapp.com），坚持永久会员承诺不变。

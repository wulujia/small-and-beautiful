# Tony Dinh — DevUtils / TypingMind

> 越南 solo 开发者，1993 年前后生（2023 年满 30 岁）。FPT University 软件工程毕业，7 年打工（越南 Silicon Straits Saigon → 新加坡 Honestbee → 新加坡 Zendesk 高级工程师，年薪约 $105K），2021 年 9 月辞职回越南做全职 indie hacker。核心叙事：build in public 的教科书样本——每月 newsletter 复盘 + X 高频输出，4 个盈利产品（2 个已卖出），TypingMind 在 OpenAI 发布 ChatGPT API 后 5 天上线，20 个月做到 $1M 收入。
> 整理日期：2026-07-16（L2 层：聚焦本人公开表达）

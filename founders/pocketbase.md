# Gani Georgiev — PocketBase

> 保加利亚开发者，PocketBase（单文件开源后端，GitHub ~59,800 星）唯一作者。零媒体露面，零访谈，零社交网络个人账号。全部公开表达集中在 GitHub discussions 和 pocketbase.io/faq。研究核心是他的"拒绝"体系：拒收 €30,000 资助、停收捐赠、关闭 PR、停审 LLM 安全报告、要求 GitHub 清零 star。

> **事实校正**：广为流传的"退还 €30,000"不准确。FLOSS/fund 批准了他登记的 €30,000 资助方案，但因拨款渠道变故，他在**款项到账前撤回申请、拒绝了资助**（2026-02-18），原话是 "withdraw my FLOSS/fund application and decline the funding"。是拒收，不是退还。

## 创业时间线

- **约 2016**——开始做 [Presentator](https://github.com/presentator/presentator)（设计稿演示与反馈工具，repo 建于 2017-04），这是 PocketBase 的源头：他需要一个能单机自部署的后端。
- **2022-07-05**——pocketbase 仓库创建。**07-07** 以 randomwebdev 发 Show HN，563 分（[HN](https://news.ycombinator.com/item?id=32013330)）；自述"过去几个月做的小开源项目"。**07-15** 发布路线图。
- **2022-10-06**——接受 Google Chrome Advanced Web Apps Fund **$20,000** 资助，11 月起全职做 PocketBase 至少 5 个月（[#730](https://github.com/pocketbase/pocketbase/discussions/730)）。
- **2024-01-21**——**停收捐赠**，归档 Open Collective、手动取消每一笔 PayPal 循环捐赠（[#4199](https://github.com/pocketbase/pocketbase/discussions/4199)）。触发点：有用户因 v1 无 ETA 表达不满。
- **2024-02-15**——宣布大重构 + 临时 feature freeze（[#4355](https://github.com/pocketbase/pocketbase/discussions/4355)）；**2024-11-24** v0.23.0 发布（Go API 全面重写，GitHub release 核实）。
- **2025-03-05**——移除 AWS SDK 依赖，自写 S3 客户端（[#6562](https://github.com/pocketbase/pocketbase/discussions/6562)）。
- **2025-09-27**——封禁高频提问用户 fayazara 引发 Reddit/GitHub 争议，他公开回应并定调维护者责任边界（[#7207](https://github.com/pocketbase/pocketbase/discussions/7207)）。
- **2025-10-27/28**——发布自写零依赖前端框架 [Shablon](https://github.com/ganigeorgiev/shablon)；宣布获 FLOSS/fund（印度 Zerodha 出资）第二期资助——即他登记的 **€30,000**/一年全职方案——计划 12 月起全职一年、2026 年底发 v1.0（[#7287](https://github.com/pocketbase/pocketbase/discussions/7287)）。
- **2026-02-18**——**拒资**：GitHub Sponsors 渠道因监管问题走不通，FLOSS/fund 改要求印度跨境电汇 + 税务居民证明、Form 10F 等一揽子文件，他以不信任对方及印度政府处理个人敏感数据为由撤回申请（[#7287 置顶更新](https://github.com/pocketbase/pocketbase/discussions/7287)；[HN 讨论](https://news.ycombinator.com/item?id=47062561)，125 分，含基金会原始邮件全文）。
- **2026-03-15**——公告假冒 X 账号，确认官方账号已停更（[#7586](https://github.com/pocketbase/pocketbase/discussions/7586)）。
- **≤2026-04-18**——**关闭外部 PR**（LLM 垃圾贡献泛滥），仅限现有协作者（[CONTRIBUTING.md](https://github.com/pocketbase/pocketbase/blob/master/CONTRIBUTING.md)，commit 历史核实该声明随 2026-04-18 newui 合并进入 master）。
- **2026-05-28**——**停审 LLM 生成的安全报告**（无论真假一律不看）；同文透露：曾请求 GitHub 支持清零项目 star 数（未果）、计划"数月内"迁离 GitHub（[#7718](https://github.com/pocketbase/pocketbase/discussions/7718)）。
- **2026-07**——现状：v0.39.7（2026-07-16 发布），59,785 星，仍是单人项目，仍未 v1.0。他有正职工作（"I have a regular job (at least for now)"），不靠开源谋生。

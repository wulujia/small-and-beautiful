## 想问的问题

1. 2023 年 5 月，产品才上线 7 个月、正在爆发期，为什么决定在那个节点卖给推文科技？三年后回头看，这个决定卖对了吗？
2. 免费版慷慨到"自带 API key 全功能免费"，Pro 的实际转化率大概什么量级？模型 token 成本怎么撑住的？

4. 从个人项目到公司、从 MPL 到 EULA，哪一步是你最不情愿但认为必须做的？
